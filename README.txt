Dipa's Makeup Studio & Beauty Saloon - website

index.html  = the complete website (photos are built in, no other files needed)

To preview: double-click index.html.
To publish: upload index.html to any web host (Netlify, Vercel, GitHub Pages, etc.).

To edit text, services, gallery, reviews, FAQ, WhatsApp number or map link:
open index.html in a text editor and search for "Editable content".

To replace the Google reviews link: edit the GOOGLE line in that same block.
