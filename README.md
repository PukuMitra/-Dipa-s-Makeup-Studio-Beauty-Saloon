## 📖 About the Project

Dipa's Makeup Studio & Beauty Saloon is a website developed to give a local beauty business a professional digital presence.

The website provides visitors with a convenient platform to explore the studio's services, view makeup inspiration, find business information, and connect with the studio for enquiries.

The project focuses on combining an elegant design with a lightweight implementation to deliver a smooth browsing experience across different devices.

---

## ✨ Features

- **Elegant User Interface:** A visually appealing design that reflects the beauty and artistry of the studio.
- **Responsive Design:** A layout designed for desktop, tablet, and mobile devices.
- **Services & Pricing:** Showcases beauty services and pricing information.
- **Makeup Gallery:** Displays makeup inspiration and beauty photography.
- **Customer Reviews:** Provides access to customer feedback.
- **Appointment Enquiries:** Makes it convenient for visitors to enquire about appointments.
- **WhatsApp Integration:** Enables direct communication with the studio.
- **Contact Information:** Displays business details and location information.
- **FAQ Section:** Provides answers to common customer questions.

---

## 💅 Services

The website showcases beauty and makeup services, including:

| Service | Description |

## 🚀 Getting Started

You can run this project locally without installing any additional dependencies.

### Prerequisites

- A modern web browser
- Git installed on your computer
- A code editor such as Visual Studio Code (optional)

### 1. Clone the Repository

```bash
git clone https://github.com/PukuMitra/-Dipa-s-Makeup-Studio-Beauty-Saloon.git
```

### 2. Navigate to the Project Directory

```bash
cd -Dipa-s-Makeup-Studio-Beauty-Saloon
```

### 3. Open the Website

Open `index.html` directly in your preferred web browser.

Alternatively, open the project folder in Visual Studio Code and use the Live Server extension.

That's it! The website is ready to run.

## ✏️ Customization

The website can be customized by editing `index.html` in any code editor.

Search for the **Editable Content** section inside the file to find the business information.

You can update:

- Studio name and description
- Services and pricing
- Gallery content
- Customer reviews
- FAQ information
- WhatsApp contact number
- Google Maps link
- Google reviews link

After making changes, save the file and refresh the browser to see the updated website.
